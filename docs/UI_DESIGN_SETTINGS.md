# UI 设计：设置页

## 目标

设置页是独立的配置工作面，不使用多层弹窗。优先显示各类功能实际使用的模型及连接来源，再管理服务地址和凭据。主题切换常驻工作区，不再占用单独设置页。

## 进入与退出

- 入口固定在项目与会话栏底部。
- 打开设置时右侧内容区由设置页替换，侧栏自动折叠以释放横向空间。
- 右上角“返回工作区”关闭设置；`Esc` 是辅助关闭方式。
- 进入前记录侧栏状态；关闭时恢复，设置期间用户手动折叠/展开优先。

## 功能模型

- 顶部并列显示“轻量高效”和“综合创作”，窄窗口改为上下排列。
- 每项显示当前模型、连接名称及完整 Base URL；未分配时明确显示“未配置”。
- 下拉选项来自各连接发现的模型列表，按连接分组；同名模型以连接 ID 区分。
- 运行参数折叠展示上下文窗口。两个功能可共用同一模型配置。
- 分析、提取、摘要和结构增强默认选轻量模型；对话、改稿和连续性审校默认选综合模型。
- 对话输入区默认“按功能自动选择”，仍可手动指定当前工作面的模型；任务正文访问策略继续独立校验。

## 模型连接

- 下方为连接列表与详情表单，支持新增、编辑、删除。
- 字段仅为连接名称、接口类型、Base URL 和可选 API Key，无模型名称输入框。
- “保存并获取模型”保存连接后调用 Ollama `/api/tags` 或 OpenAI 兼容 `/models`；另有刷新入口。
- “智能分配”使用当前连接已发现的模型，优先匹配 MiniCPM4.1 8B 与 Qwen3 8B，再按模型名称中的轻量标识推荐。它不是性能评测，也不自动下载模型。
- API Key 仅进入系统凭据库；模型通过连接 ID 共用凭据。修改连接后相关模型读取新地址与凭据。
- 旧模型保留原 ID，迁移为独立连接，避免合并同 URL 但不同凭据的配置。
- 删除连接前确认，同时删除相关模型配置并清空功能分配。
- 本机 Ollama 提供默认开启的自动停止开关及手动“停止驻留”；其他会话有任务运行时不自动卸载旧模型。

## 主题入口

- 日/月图标位于项目与会话栏顶部、折叠按钮左侧，悬停显示将切换的主题。
- 侧栏折叠后图标纵向排列，保留主题入口。
- 偏好保存在本机，并沿用原生窗口主题同步。

## 状态

- 初始空连接列表：新增表单仍可用，删除最后一项不会恢复默认演示连接。
- 获取中/保存中：禁用重复操作；任务执行期间禁止更改连接和功能分配。
- 连接失败：保留已保存配置，显示错误并支持刷新重试；空列表不启用智能分配。
- 当前模型不在最新列表中：保留当前选择并显示可用性提示。
- 离开有未保存修改的表单：请求确认放弃。
- 浏览器预览明确标为演示，列表为模拟数据；真实发现与凭据访问由桌面端完成。
