# UI 设计：模型与连接设置

## 目标

设置页是独立的模型配置工作面。产品只启用一个功能模型，Skill 根据任务场景调整提示词、上下文和处理流程。页面负责连接管理、格式能力准入、唯一活动模型选择与本机硬件信息，不提供运行策略或对话内模型切换。

## 页面结构

页面由工具栏、全局反馈、主内容区和右侧信息栏组成：

1. 工具栏显示 `MODEL SETTINGS`、页面标题“模型与连接”、当前环境说明和返回按钮。
2. 全局反馈仅在保存、删除、选择模型或探测产生结果时出现。
3. 主内容区依次显示“当前模型”和“模型连接”。
4. 右侧信息栏显示“本机环境”和“格式准入”。

桌面宽度下，主内容区和信息栏按 `minmax(0, 1fr) 260px` 排列。容器宽度小于 `900px` 时信息栏移到主内容下方并分成两列；视口宽度小于 `700px` 时改为单列。

## 当前模型

- 下拉框的可访问名称为“当前功能模型”。
- 可选项只来自当前已缓存且格式准入通过的连接与模型组合。
- 已保存但没有有效探测结果的活动模型仍显示，并标记“结构化输出待验证”，避免重开应用后静默替换用户选择。
- 状态只使用“格式准入通过”“需要重新探测”和“等待选择”，不把硬件档位或未验证能力写成模型状态。
- 元信息显示连接名称、配置的上下文窗口，以及“结构化输出已验证/待验证”。
- “运行参数”折叠区只编辑活动模型的上下文窗口。该数值是请求配置，不代表已实测的最大上下文能力。

## 模型连接

- 左侧连接列表显示连接名称、Base URL、探测进度或通过数量。
- 状态点固定在右侧操作栏上方；删除按钮位于其下方，悬停、选中或键盘聚焦时显示。
- 右侧表单字段为“连接名称”“接口协议”“Base URL”和“API Key”。API Key 是否必填由目标服务决定，因此空值提示为“按服务要求填写”。
- 新建连接只打开未保存表单，不自动发现或探测模型。
- “保存并探测全部模型”先保存连接，再获取模型目录，最后顺序探测目录中的全部模型。
- 一个页面最多展开一个连接的探测结果。折叠按钮使用“查看探测结果/收起探测结果”。
- 刷新按钮只重新获取模型目录，并清除该连接的旧准入结果；其提示必须明确这一副作用。
- “重新探测全部模型”不修改连接配置，只重新验证当前目录中的模型。

## 格式能力准入

当前自动探测验证以下事实：

1. 连接能够返回模型目录。
2. Ollama 接口接受 `format` Schema，或 OpenAI 兼容接口接受 `response_format: json_schema`。
3. 返回内容能解析为 JSON，并符合探测约定的字段和值。

探测不评测中文创作质量，也不证明模型的最大上下文窗口达到配置值。因此页面不使用“中文能力已验证”或“上下文达标”等标签。中文质量与实际上下文容量属于独立的产品测试和运行时验证。

本机 Ollama 的每个候选模型完成探测后都会发送 `keep_alive: 0`，避免探测模型堆积影响后续显存测量。该行为没有用户开关。

## 本机环境

- “最低配置”“标准配置”“推荐配置”只描述本机内存和独立显存档位，不代表当前模型已经适配该设备。
- 无法读取必要硬件信息时显示“硬件未确认”；低于最低门槛时显示“低于最低配置”。
- 硬件不足或无法确认时提供“添加远程连接”入口。

## 数据与状态

- 模型目录和准入结果缓存在 `vinkey.modelProbeCache`，按连接 ID、接口协议和 Base URL 校验。
- API Key 不写入该缓存；桌面端凭据由系统凭据库管理。
- 无匹配缓存的已保存连接在设置页打开时只获取模型目录，不自动运行全部格式探测。
- 保存连接或用户明确点击重新探测时才执行全部模型探测。
- 删除连接会同时删除模型配置、准入缓存，并由 Store 校正唯一活动模型。
- 任务执行期间锁定连接和活动模型修改；探测中的连接不能删除。
- 离开存在未保存修改的表单前需要确认。
- 浏览器模式使用模拟连接和探测结果；真实请求与凭据访问仅由桌面端执行。
