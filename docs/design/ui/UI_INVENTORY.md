# Vinkey UI 现状盘点

- 盘点日期：2026-09-23
- 对比基线：2026-09-02 盘点；重点核对 2026-09-03 至 `a5e882b` 的实现提交
- 依据：`src/App.tsx`、`src/components/*`、`src/store.ts`、`src/styles.css`、`src/lib/desktop.ts`、[UI_ENTRY_POINTS.md](./UI_ENTRY_POINTS.md) 和各 `UI_DESIGN_*.md` 的组件映射

## 0. 统计结论

- **13 类 UI 界面/表面**：Windows 标题栏、macOS 原生窗口区、项目与会话侧栏、对话页、文件列表页、文件编辑页、日志中心、设置页、AI 修改提案条、分析产物预览、删除确认、应用诊断日志、全局错误/状态反馈。
- **8 个功能域 + 1 个质量基线**：`D-SHELL` 应用壳层、`D-NAV` 项目与会话导航、`D-EDITOR` 文件与编辑器、`D-MODEL` 模型设置、`D-INTENT` IntentRouter、`D-CHAT` 对话、`D-CONTEXT` 上下文分析、`D-REVISION` AI 改稿、`D-TASK-LOG` 日志与长任务，以及 `Q-RESP` 响应式/主题/焦点回归。
- **22 个源码组件/组件函数**：`App`、`TitleBar`、`IconButton`、`ContentPanel`、`ProjectSessionSidebar`、`FileBrowserPanel`、`WorkspaceTree`、`TreeItem`、`FileWorkspace`、`EditorPanel`、`CodeEditor`、`ChatPanel`、`ChatMessageItem`、`MarkdownContent`、`MessageActivity`、`LogCenter`、`ConversationTaskControls`、`SettingsPage`、`ModelPicker`、`FilePreview`、`RecordDeletionDialog`、`CodeBlock`。
- **83 类业务语义 UI 组件模式**：包含入口、操作、输入、确认、状态和结果组件，关联 50 个稳定业务功能点；按页面或交互域登记在对应 `UI_DESIGN_*.md`。
- **5 类跨域状态**：本机工作区/多项目与会话状态、文档编辑与修改提案、模型连接/活动模型状态、流式对话/分析活动状态、可恢复后台任务状态。

## 3. 当前可见交互清单

跨页面业务功能入口、前置条件和跳转目标统一见 [UI_ENTRY_POINTS.md](./UI_ENTRY_POINTS.md)；交互和结果组件与业务功能点的映射按页面见对应 `UI_DESIGN_*.md`。本节只保留当前实现的可见交互事实。

### 导航与窗口

- Windows 自绘标题栏双击切换最大化；按钮执行最小化、最大化/还原、关闭。
- macOS 使用原生全局菜单；菜单命令与 Windows 保持同一集合。
- 顶部“对话/文件/日志”是互斥页面切换；进入“文件”时默认收起编辑器。
- 设置打开时自动折叠侧栏；关闭时恢复进入前状态，设置期间手动切换优先。
- 侧栏支持多项目展开/切换，项目和会话删除均经过确认对话框；主题可在侧栏和应用菜单切换。
- macOS 原生窗口按钮会根据侧栏宽度同步布局；窄窗口下设置页和标题栏有专用响应式规则。

### 工作区与搜索

- 打开项目后显示名称和路径；可刷新或切换项目。
- 侧栏搜索同时匹配会话标题和文档正文，文档结果显示路径、行号和摘要。
- 文件页支持名称筛选；目录可展开/收起；文件左键打开，右键切换对话上下文。
- 新建文档和文件夹通过路径输入完成；新建文档后自动打开编辑器。

### 对话

- 没有模型时发送操作转入设置；有模型时按上下文预算决定是否允许发送。
- Enter 发送，Shift+Enter 换行，中文 IME 组字期间不发送。
- 生成时发送按钮变为停止；文本按 chunk 追加到同一条助手消息。
- 每条有内容的消息支持复制；失败显示全局错误条。
- 输入 `@` 后可按文件名/相对路径筛选，使用方向键、Enter/Tab 将文件加入上下文。
- 已引用文件显示为可移除标签；文档分析、人物线、项目分析提供快捷入口。
- 长任务显示可折叠活动轨迹，包含读取、分析、证据校验和产物路径等状态。

### 文档

- Markdown 支持编辑/分栏/预览；TXT 仅编辑。
- 修改内容后显示未保存标记；保存仅更新原位状态。
- 状态栏显示行数、字符数、词数、编码、换行符和保存状态。
- `Ctrl/Cmd+S` 和标题栏“保存文档”都保存当前活动文档。
- AI 改稿结果在文件页显示修改提案条，支持接受或拒绝；接受后仍保留未保存状态。
- 图片、PDF、音视频和二进制文件进入预览/下载路径；Markdown 预览使用安全渲染。

### 日志中心

- “日志中心”显示运行、完成和失败计数，按记录展开步骤与检查点。
- 日志中心只读展示失败原因和业务事件；失败重试由任务来源会话处理。
- 展开已完成任务时自动按需读取分析产物，显示模型调用、缓存命中、耗时和产物路径；读取失败可在详情内重新加载。
- 右上角提供“历史记录清除 / 刷新”；历史记录清除需要确认，只清除当前项目终态任务记录，不删除分析产物。
- 有来源的任务可返回来源会话；任务展开后可在详情末尾复制诊断摘要，且摘要不包含正文、凭据或隐藏思维链。

### 设置

- 模型类型为 Ollama 或 OpenAI 兼容；当前模型为应用级唯一活动模型。
- 服务支持发现模型、顺序准入检查、检查结果缓存、上下文自动配置和硬件档位提示。
- 连接按规范化服务地址 + API Key 指纹去重；同地址不同密钥可共存，名称不参与去重。
- API Key 不写入 SQLite、浏览器持久化存储或日志；桌面端使用系统凭据库，浏览器模式仅保存不可逆指纹。
- 模型选择器支持键盘操作、根据可用空间向上/向下展开，并保留“需要检查”的已保存当前模型。
- 外观目前只有深色/浅色主题。

## 4. 状态与数据边界

| 状态 | 目前表现 | 目标态缺口 |
| --- | --- | --- |
| 未打开工作区 | 侧栏/文件页显示打开项目或打开文件夹 | 最近工作区入口需明确化 |
| 未配置模型 | 输入区显示“添加模型” | 对话页可提供更明确的引导 |
| 搜索中 | 侧栏显示正在搜索文档 | 需要加载态尺寸稳定验收 |
| 上下文超限 | 发送被阻止，错误条提示移除/缩短 | 应标出超额文件并提供逐项移除 |
| 未保存 | 标签点、状态栏“未保存”、保存按钮可用 | 外部冲突与统一放弃修改确认待实现 |
| 连接失败 | 设置页内联连接结果、模型列表错误和全局错误条 | 统一重试和错误文案 |
| AI 修改提案 | 对话页提示，文件编辑页显示提案条，可接受/拒绝 | 多块批量审核、放弃全部和更完整 diff 视图待实现 |
| 分析活动 | 消息内折叠轨迹、日志中心显示步骤、检查点和公开事件 | 来源会话按持久化任务状态提供统一控制 |
| 后台任务失败 | 日志中心显示失败原因并返回来源会话，来源会话选择步骤重试 | 跨项目任务通知待实现 |
| 项目/会话删除 | 原生确认对话框，项目删除要求输入确认词 | 统一对话框组件待实现 |
| 模型连接重复 | 保存前校验，数据库唯一索引，历史重复迁移 | UI 中尚未提供“已存在连接”专用冲突定位 |

## 5. 设计稿与实现的主要差异

1. 当前提案审核是编辑器内联基础视图，设计稿要求的完整 diff、接受全部/逐块审核、放弃提案流程仍未完全实现。
2. 设计稿列出的编辑器、数据、权限等设置分组尚未实现，目前设置页聚焦模型服务和外观主题。
3. 设计稿建议的 toast、统一原生确认对话框和统一内联重试还未形成公共组件，当前仍混用 `alert`、`prompt`、`confirm`、错误条和局部对话框。
4. `EditorPanel` 目前数据模型保留 `tabs`，但 UI 仍没有多标签切换；外部文件冲突、对比、重新加载和另存为也未实现。
