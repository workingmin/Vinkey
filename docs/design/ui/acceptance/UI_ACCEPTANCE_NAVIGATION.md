- 更新日期：`2026-09-23`

## 1. 验收边界

本报告不再把项目、会话和搜索归入壳层结构验收。它按依赖分三次判定：

| 门槛 | 可证明 | 不能证明 |
| --- | --- | --- |
| `W0-NAV-F` | 隔离 fixture/SQLite 下的项目、会话、删除和当前搜索合同 | 真实模型、多轮对话质量、语义标题、全局搜索目标态 |
| `W2-NAV-E` | 真实多轮会话、标题生命周期、持久化和搜索跳转 | 运行任务或未保存文档下的全部跨域保护 |
| `W4-NAV-R` | 任务、编辑器与导航交叉状态的保护和过期响应处理 | 不重复证明全部基础 CRUD |

`W0-NAV-F` 不依赖 Ollama。`W2-NAV-E` 必须使用已通过模型设置准入的真实模型。`W4-NAV-R` 必须构造运行任务和未保存文档状态。

## 7. 测试人员必须回传的材料

### 7.1 `W0-NAV-F`

- 操作系统、架构、DPI、Vinkey 版本和 Git SHA。
- fixture manifest：脱敏路径、项目/会话/文档数量、生成方式和清理结果。
- 命令、退出码、stdout、stderr、`result.json` 和 `SHA256SUMS`。
- 项目切换、会话恢复、删除确认、搜索结果/无结果、错误重试截图或录屏。

### 7.2 `W2-NAV-E`

- Ollama/兼容服务版本、模型标签、profile ID（不含密钥）。
- 每个项目和会话的脱敏标识、轮次数、临时标题、语义标题和刷新后结果。
- 全局搜索各入口、结果分组、跳转目标、Escape 返回的截图或录屏。
- 模型不可用、标题升级失败和搜索失败的恢复证据。

### 7.3 `W4-NAV-R`

- 运行任务、生成中会话和未保存文档的前置状态证据。
- 切换/删除的实际提示、用户选择、最终目标和源状态完整性。
- 延迟搜索或加载响应被丢弃的机器断言或诊断日志。

不得回传 API Key、完整作品正文、系统用户名或未脱敏绝对路径。测试人员使用[导航本地验收回填模板](./UI_ACCEPTANCE_NAVIGATION_RUN_TEMPLATE.md)填写；未执行项保持 `待回填` 或 `BLOCKED`。

## 8. 当前结论

- `W0-NAV-F`：待脚本和本地 fixture 证据，当前不可判定通过。
- `W2-NAV-E`：部分用例因 `CF-022`、`CF-023` 和实现缺失而阻断。
- `W4-NAV-R`：等待对话、编辑器和长任务域形成可复现前置状态。
- `D-NAV` 综合结论：**未完成验收**。当前源码基线可作为脚本设计依据，不能替代三个门槛的执行证据。
