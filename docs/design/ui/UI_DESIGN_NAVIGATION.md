## 1. 文档总述

### 1.1 目标

本功能域负责用户在多个本地项目和多条会话之间定位、切换、恢复与搜索。设计必须同时满足：

- 项目、会话和搜索结果始终带有可辨认的范围，不把不同工作区的数据混在一起。
- 不配置模型时，也能通过隔离 fixture 验证基础记录、切换、删除和搜索合同。
- 依赖真实对话产生的数据，只在模型设置和对话链路通过后验收。
- 运行任务或未保存文档存在时，切换和删除不能静默丢失状态。

### 1.2 责任边界

| 本文负责 | 其他文档负责 |
| --- | --- |
| 工作区/项目登记、项目切换和项目记录删除 | 窗口、菜单、侧栏宽度、内容页容器：[UI_DESIGN_SHELL.md](./UI_DESIGN_SHELL.md) |
| 会话新建、恢复、删除、标题生命周期和跨项目隔离 | 消息发送、流式生成和停止：[UI_DESIGN_CHAT.md](./UI_DESIGN_CHAT.md) |
| 侧栏现有搜索、目标全局搜索入口、结果分组和跳转 | 文件打开、编辑和结果定位：[UI_DESIGN_EDITOR.md](./UI_DESIGN_EDITOR.md) |
| 导航域的加载、空态、错误、确认和保护状态 | 通用状态规则：[UI_DESIGN_STATES.md](./UI_DESIGN_STATES.md) |

`D-SHELL` 提供稳定的侧栏和内容区承载，`D-NAV` 决定其中的项目、会话和搜索业务。壳层结构通过不等于导航业务通过。

### 1.3 术语

| 术语 | 规范含义 |
| --- | --- |
| 工作区（workspace） | 当前授权并打开的本地目录及其文件访问边界 |
| 项目（project） | Vinkey 数据库中的登记记录，可指向一个工作区 |
| 会话（conversation） | 绑定项目的消息、标题、运行状态和时间信息 |
| 侧栏快速搜索 | 当前已实现的内联输入框，同时筛选项目/会话并搜索当前工作区正文 |
| 全局搜索 | 目标态统一面板，可从展开/折叠侧栏、标题栏或键盘命令进入 |
| 临时标题 | 不额外调用模型，由首次有效用户输入确定性生成的标题 |
| 语义标题 | 基于已完成对话内容生成且受生命周期规则约束的稳定标题 |

### 1.4 非目标

本域不引入云端项目、团队空间、全文云索引、外部 Agent CLI 会话接管或跨设备同步。正文搜索默认不越过当前授权工作区；跨项目只搜索 Vinkey 已登记的项目和会话元数据。

## 3. 信息结构与依赖

```text
D-SHELL：窗口、标题栏、侧栏容器、内容区容器
└─ D-NAV：项目、会话、搜索与跳转
   ├─ W0-NAV-F：隔离 fixture / SQLite 合同
   ├─ W2-NAV-E：真实多轮对话、标题与搜索跳转
   └─ W4-NAV-R：运行任务和未保存文档下的跨域回归
```

| 依赖 | 对导航域的影响 |
| --- | --- |
| `D-SHELL` | 提供可见、可聚焦的侧栏和全局入口承载 |

## 4. 项目与会话设计

### 4.1 项目操作

- 重复添加同一目录时选择已有项目记录，不创建重复记录。
- 项目行显示名称、可辨认的路径、选中状态、展开状态、新建会话和删除记录入口。
- 切换项目前检查运行任务和未保存文档；异步加载完成后再次校验当前 `workspaceId`。
- 删除项目采用准确名称二次确认，只删除 Vinkey 的项目、会话和消息记录，不删除用户目录、附件或正文。
- 加载失败保留项目行和重试入口，不以空列表伪装加载成功。

### 4.2 会话操作

- 新建会话绑定明确的目标项目，必要时先完成项目切换，再进入对话页。
- 恢复会话同时恢复标题、消息和持久化运行结果，不串写其他项目。
- 会话项显示标题、消息数、更新时间和运行状态；运行中会话禁止删除。
- 删除会话需确认，失败时保留对话框和重试能力。

### 4.3 会话标题生命周期

当前代码在创建会话时将首次用户输入合并空白并截取前 28 个字符作为标题；这只是确定性 fallback，不是“对话摘要”。

| 阶段 | 目标规则 | 实现状态 |
| --- | --- | --- |
| 新会话 | 使用“新会话”等稳定占位，不因空输入生成无意义标题 | 已实现 |
| 首次有效输入 | 合并空白并截取前 28 个字符形成临时标题；不调用额外模型 | 已实现 |
| 第一轮完成或累计 2 至 3 条用户输入 | 可执行一次语义标题升级；应概括稳定主题，不使用最后一轮问题持续覆盖 | 待实现；`CF-022` 待参考 |
| 自动升级失败/模型不可用/隐私策略禁止额外调用 | 保留临时标题，不阻断消息保存和会话恢复 | 待实现 |
| 用户手动重命名 | 用户标题优先，之后停止自动改名，除非用户明确要求重新生成 | 待实现 |
| 最近活动展示 | 最近问题可作为副标题或活动摘要，不替换稳定主标题 | 待实现 |

语义标题请求必须绑定会话 ID、项目 ID 和消息版本；响应返回时任一条件变化即丢弃，不能覆盖手动标题或写入其他项目。

## 5. 搜索设计

### 5.1 当前实现

当前 `ProjectSessionSidebar` 提供内联搜索：

- 前端过滤项目名称、路径和会话标题。
- 输入停止 220ms 后调用桌面桥接搜索当前工作区正文。
- Rust 按文件逐行搜索并限制最多 100 条结果。
- 侧栏折叠或窗口宽度不大于 700px 时，该输入框不可见。

该实现可纳入 `W0-NAV-F` 验证，但不能作为目标全局搜索已完成的证据。

### 5.2 目标全局搜索

目标态新增 `BF-SEARCH-001` / `EP-SEARCH-001`：

- 标题栏、侧栏展开态、侧栏折叠态和统一键盘命令打开同一个搜索面板。
- 图标使用项目已启用的 Lucide `Search`，提供 tooltip、`aria-label` 和可见焦点，不复制外部产品的 SVG 或 CSS 类。
- 结果按“项目”“会话”“当前项目文档”分组；每项显示范围、匹配文本和目标类型。
- 项目/会话元数据可覆盖已登记项目；正文默认只搜索当前授权工作区。
- `Enter` 打开选中结果，`Escape` 关闭并把焦点返回触发入口；跳转失败保留查询和结果。
- 若保留侧栏内联输入框，其名称和行为改为“快速筛选”，不能与全局搜索形成两套同名语义。

全局搜索面板、入口和快捷键目前均为待实现；最终形态须在 `CF-023` 竞品证据和快捷键冲突检查完成后冻结。

## 6. 状态、响应式与可访问性

| 状态 | 设计要求 |
| --- | --- |
| 加载中 | 项目和会话保留稳定占位；搜索显示进度且不清空已有查询 |
| 空态 | 区分无项目、项目无会话、无搜索结果和工作区无文档 |
| 错误 | 错误留在所属项目、会话或搜索面板；重试不重复创建记录 |
| 项目切换 | 运行任务阻断；未保存文档要求保存、放弃或返回；成功后清理旧域状态 |
| 删除 | 显示删除范围；运行中禁用；失败保留输入和确认上下文 |
| 过期响应 | `workspaceId`、项目 ID、会话 ID 或查询版本不匹配时丢弃 |
| 折叠/窄窗口 | 核心全局搜索入口仍可达；当前缺失属于待实现问题 |

所有图标入口必须有可读名称；项目路径、会话标题和搜索摘要可截断，但应提供不泄露隐私的完整值查看方式。搜索面板打开后焦点进入输入框，结果使用可预测的方向键顺序，关闭后返回原入口。

## 9. 验收标准

### 9.1 `W0-NAV-F`：fixture/合同门槛

- 使用隔离临时目录和测试数据库验证至少两个项目、每项目至少两条会话。
- 验证添加、重复添加、展开、切换、恢复、删除确认、加载错误和重试。
- 验证当前侧栏搜索的项目/会话过滤和当前工作区正文边界。
- 不要求 Ollama，不生成真实语义标题，不据此宣称多轮对话通过。

### 9.2 `W2-NAV-E`：真实端到端门槛

- 在已通过 `D-MODEL` 和 `D-CHAT` 的环境中创建多项目、多会话和多轮对话。
- 验证标题生命周期、刷新后持久化、跨项目恢复和全局搜索结果跳转。
- `CF-022`、`CF-023` 未定稿或对应实现未完成时，相关用例必须标记 `BLOCKED`，不能降格为通过。

### 9.3 `W4-NAV-R`：跨域回归门槛

- 在后台任务运行、会话生成、未保存文档和异步搜索返回期间执行切换或删除。
- 验证阻断、确认、取消、保存后继续和过期结果丢弃。
- 只复核跨域风险，不重复 `W0-NAV-F` 的全部基础数据合同。

执行矩阵、当前阻断和测试人员材料见[项目与会话导航验收报告](./acceptance/UI_ACCEPTANCE_NAVIGATION.md)。
