# UI 设计：状态、流程与验收

## 首次打开

- 应用直接进入工作台，不显示营销落地页。
- 未打开工作区时，侧栏提供打开项目；文件页提供打开文件夹。
- 对话页保持可用；未配置模型时显示添加模型入口。
- 浏览器调试模式可以载入演示工作区，不访问本机目录。

## 核心流程

### 打开和保存文档

1. 文件页先显示文件列表，选择文档后展开编辑器。
2. 编辑后标签和状态栏显示未保存。
3. 保存成功只更新原位状态。
4. 外部变更进入冲突状态，提供对比、重新加载、另存为（目标态）。
5. 收起编辑器只关闭编辑器，不离开文件列表。

### 附加上下文

当前从文件树右键添加/移除文档；输入区上方展示已引用文件，发送时只提交这些文件。目标态增加 `@` 搜索、键盘筛选、超额文件标记和逐项移除。

### AI 改稿审核

```text
AI 返回结果
├─ 普通回答：留在消息流，可复制或插入
└─ 文档修改：文件页打开 diff 审核
   ├─ 接受全部
   ├─ 逐块接受/拒绝
   ├─ 放弃提案
   └─ 返回对话继续调整
```

当前 diff 审核尚未实现，不能把 AI 生成内容静默写入正文。

## 空态、加载和错误

| 状态 | 设计表现 |
| --- | --- |
| 未选工作区 | 打开文件夹主操作；保留可理解的本地状态说明 |
| 工作区为空 | 新建 Markdown、新建 TXT 或文件夹的明确命令 |
| 未打开文档 | 文件列表占满右侧；对话页不受影响 |
| 未配置模型 | 对话输入区显示添加模型 |
| 模型不可用 | 模型状态、内联错误和重试 |
| 搜索中 | 结果区显示稳定尺寸的加载状态 |
| 文件无权限 | 保留草稿，提供重新授权或另存为 |
| 上下文超限 | 标出超额文件，禁用发送并提供移除 |
| 未保存/外部冲突 | 标签点、状态栏、冲突条分别表达，不只依赖颜色 |

## 跨平台和响应式验收

- Windows 和 macOS 的命令集合、内容区布局和状态语义一致。
- 在 1440×900、1280×800、1024×680 下无文字、面板和按钮重叠。
- 右侧内容区始终最大；文件页列表态与编辑态都能返回对话。
- 长文件名、模型名、路径和上下文标签在窄宽度下截断而不挤压图标。
- 深浅主题均通过对比度、键盘焦点、中文 IME 和减少动态效果检查。

## 实现优先级

1. 统一设计 token、基础控件和错误反馈。
2. 完善壳层、搜索、空态和响应式边界。
3. 精调对话输入、上下文展示、流式生成和消息操作。
4. 精调文件列表、编辑器状态、预览和保存反馈。
5. 补齐 diff 审核、外部冲突和 `@` 引用。
6. 扩展设置分组并执行 Windows/macOS 验收。
