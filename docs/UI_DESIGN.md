# Vinkey UI 设计方案

- 状态：已确定，作为首版 UI 实现基线
- 日期：2026-08-24
- 适用端：Windows、macOS 桌面应用

## 1. 设计结论

Vinkey 采用 **深色、安静、写作优先的多栏桌面工作台**。

参考页面中“全局导航 + 项目文件树 + 主工作区 + 辅助面板”的结构适合桌面创作工具，但 Vinkey 调整其信息优先级：

- 文档编辑器是主区，始终占据最大面积。
- AI 是可收起的辅助面板，不取代编辑器。
- Markdown 预览在编辑区内以“编辑 / 分栏 / 预览”切换，不长期占用独立固定栏。
- 全局导航压缩为图标工具轨，去掉与本地产品无关的容量、商城和升级入口。
- AI 生成结果不使用阻塞式居中弹窗，改为可审核的内联差异面板。

## 2. 设计原则

### 2.1 写作优先

打开工作区后，视觉焦点直接落在文档和光标上。界面不使用营销式欢迎页、大标题、装饰图形或大量悬浮卡片。

### 2.2 本地状态可见

当前工作区、文件相对路径、保存状态、当前模型和附加上下文必须清晰可见。不用“已同步”等云产品语言表达本地保存。

### 2.3 AI 操作可审核

AI 可以回答、生成草稿和提交修改建议，但不得无提示覆盖正文。修改类结果必须显示差异，并由用户选择接受、拒绝或继续调整。

### 2.4 稳定不跳动

工具栏、图标按钮、标签页、状态栏和输入区使用稳定尺寸。流式输出、文件名变化和状态标记不得导致主布局频繁位移。

## 3. 主窗口信息架构

    ┌─ 系统标题栏 / 工作区标题 / 当前模型 / 窗口控制 ───────────────────────────┐
    │工具轨│工作区文件│        文档编辑与预览主区        │     AI 助手     │
    │ 48px │ 260px   │                                  │     400px       │
    │      │工作区头部│ 文档标签页                       │ 会话/模型头部   │
    │ 文件 │文件树    │ 路径、编辑工具、视图切换         │ 上下文文件条    │
    │ 搜索 │          │                                  │ 消息流          │
    │ 会话 │          │      CodeMirror / Markdown       │                 │
    │      │          │                                  │ 修改提案 / diff │
    │ 设置 │          │ 行列、字数、编码、保存状态       │ 输入区          │
    └──────┴──────────┴──────────────────────────────────┴─────────────────┘

推荐初始窗口为 1440 × 900px，最小窗口为 1024 × 680px。

### 3.1 工具轨

工具轨默认宽度 48px，只使用 Lucide 图标，不放置长文字导航。

| 位置 | 命令 | 图标 |
| --- | --- | --- |
| 顶部 | 工作区文件 | Files |
| 顶部 | 全局搜索 | Search |
| 顶部 | 历史会话 | MessagesSquare |
| 底部 | 模型与应用设置 | Settings |

每个图标按钮为 32 × 32px，图标为 16px，悬停显示文字提示。当前模块使用左侧 2px 强调线和浅色图标，不使用大面积彩色底。

### 3.2 工作区文件面板

- 默认宽度 260px，允许在 220-360px 内拖动调整。
- 头部显示工作区名，右侧提供新建文件、新建文件夹、刷新和更多菜单。
- 文件树默认展示 Markdown 和 TXT；其他文件可选择显示，但不自动读取内容。
- 文件类型使用 FileText、FileType、Folder、FolderOpen 图标，不使用 emoji。
- 当前文件行使用中性选中底色和左侧强调线。
- 未保存文件显示固定尺寸圆点，不改变行宽。
- 删除需要确认并优先移入系统回收站。

### 3.3 文档主区

文档主区按以下顺序排列：

1. 36px 文档标签栏：文件图标、文件名、未保存标记、关闭图标。
2. 40px 文档工具栏：相对路径、撤销、重做、搜索、视图切换和 AI 面板开关。
3. 可伸缩编辑区：CodeMirror 源文本和可选 Markdown 预览。
4. 24px 状态栏：行列、字符数、字数、UTF-8、LF/CRLF 和保存状态。

编辑视图使用三段式切换：

- **编辑**：单栏 CodeMirror，默认视图。
- **分栏**：编辑器和 Markdown 预览各占一半，中间可拖动。
- **预览**：单栏阅读视图。

模式切换使用紧凑分段控件。TXT 文件禁用预览模式。

### 3.4 AI 助手面板

- 默认宽度 400px，允许在 340-520px 内拖动调整。
- 可通过 PanelRight 图标收起，收起后编辑区自动填满空间。
- 头部包含会话选择、新建会话、当前模型和连接状态。
- 上下文文件位于消息流上方的独立水平条中，每个文件显示为可移除标签。
- AI 消息使用无边框文本块；用户消息使用弱底色区分，不把所有消息做成卡片。
- 输入区高度在 96-220px 之间随内容增长。
- 输入区提供附件、模式菜单和发送按钮。
- 生成期间发送按钮变为固定尺寸的停止图标，避免布局变化。

## 4. 核心交互流程

### 4.1 首次打开

应用首屏仍是工作台壳层，不是落地页：

- 文件面板显示“打开文件夹”主操作。
- 主区显示最近工作区和“新建文稿”入口。
- AI 面板默认收起；没有可用文档时不展示空白聊天框。

### 4.2 打开与保存文档

1. 点击文件树中的文稿，在主区新建或聚焦标签页。
2. 编辑后，标签页和状态栏显示未保存状态。
3. 保存成功只更新原位状态，不弹出成功通知。
4. 外部程序改变文件时，在文档工具栏显示持久冲突条。
5. 冲突条提供对比、重新加载和另存为，不静默覆盖。

### 4.3 附加上下文

支持三种方式：

- 从文件树拖入 AI 面板。
- 在文件树右键选择“添加到当前会话”。
- 通过 AI 输入区的 Paperclip 图标选择文件。

附加后显示文件名、大小和上下文占用估算。只有上下文条中明确列出的文件才随请求发送给模型。

### 4.4 AI 改稿审核

    AI 返回修改提案
            │
            ├─ 普通回答 → 留在消息流，可复制或插入光标处
            │
            └─ 文档修改 → 打开编辑区底部 diff 面板
                             │
                             ├─ 接受全部
                             ├─ 逐块接受或拒绝
                             ├─ 放弃提案
                             └─ 返回会话继续调整

diff 不只依赖红绿色：删除行同时使用 Minus 图标和左边标，新增行使用 Plus 图标和左边标。审核面板不覆盖原文，不强制中断阅读。

### 5.2 字体与字号

- UI 字体：system-ui、-apple-system、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif。
- 编辑字体：默认跟随 UI 字体，设置中允许选择等宽或本机字体。
- 代码和 Markdown 标记：ui-monospace、SFMono-Regular、Consolas、monospace。
- UI 常规字号 13px，面板标题 13px/600，辅助文字 12px。
- 编辑正文默认 16px，行高 1.8，用户可调整。
- 所有文字使用零字距，字号不随视口宽度缩放。

### 5.3 尺寸、间距与圆角

- 基础间距网格为 4px，常用间距为 4、8、12、16、24px。
- 图标按钮为 28px 或 32px，图标 16px。
- 常规输入框高 32px；多行会话输入自适应高度。
- 常驻面板不用悬浮卡片外观，直接以 1px 分隔线组织。
- 菜单、输入框、消息弱底色块圆角 6px。
- 对话框和真正浮层圆角 8px，不使用超大圆角。

### 5.4 阴影和动效

- 常驻面板无阴影，仅菜单、对话框和拖动浮层使用阴影。
- 微交互时长 120-180ms，面板展开收起 180-220ms。
- 流式 AI 内容只追加文字，不为每个 token 添加动画。
- 遵循系统“减少动态效果”偏好。

## 6. 组件规范

### 6.1 按钮

- 保存、撤销、重做、附件、刷新、收起面板等熟悉命令使用 Lucide 图标按钮和 tooltip。
- “打开文件夹”“接受全部”“另存为”等明确命令使用图标加文字。
- 同一操作区只有一个主按钮。
- 危险操作不使用主强调色。

### 6.2 标签和状态

- 文档上下文标签使用文件图标、截断文件名和移除图标。
- 连接状态使用状态点加模型名，不只依赖颜色。
- 标签高度固定为 24px，长文件名省略，悬停显示完整相对路径。

### 6.3 菜单和对话框

- 文件操作、视图选项和模型选择使用菜单。
- 设置使用独立页面，不塞入多层弹窗。
- 只有删除、放弃未保存修改、覆盖外部变更等阻断决策使用对话框。

### 6.4 通知

- 保存成功和连接成功不弹 toast，只更新原位状态。
- 可恢复的失败使用面板内联提示并提供重试。
- 跨面板且不需要立即决策的结果才使用右下角 toast。

## 7. 主要页面和状态

### 7.1 工作台

工作台是默认页，包含文件树、文档主区和可选 AI 面板。不设置单独首页仪表盘。

### 7.2 搜索

搜索复用左侧面板，不覆盖编辑器。结果按文件分组，显示相对路径、匹配行和简短摘要，点击后定位到编辑器行。

### 7.3 会话历史

会话历史复用左侧面板，显示标题、更新时间、模型和上下文数量。选择会话后打开 AI 面板，不把主编辑区替换为全屏聊天页。

### 7.4 设置

设置在主区打开，左侧使用分组导航：

- 通用：主题、语言、启动和更新。
- 编辑器：字体、字号、行高、自动换行和自动保存。
- 模型：Ollama 和 OpenAI 兼容提供商、地址、模型和连接测试。
- 数据：会话数据位置、导出、删除和日志。
- 权限：已授权工作区及撤销授权。

### 7.5 空态与错误态

| 状态 | 表现 |
| --- | --- |
| 未选工作区 | 打开文件夹按钮 + 最近工作区 |
| 工作区为空 | 新建 Markdown、新建 TXT 两个明确命令 |
| 未打开文档 | 显示最近文档，不显示装饰插图 |
| 未配置模型 | AI 面板显示“添加模型”命令 |
| 模型不可用 | 头部状态点 + 内联错误 + 重试 |
| 文件无权限 | 保留当前草稿，提供重新授权或另存为 |
| 上下文超限 | 标出超额文件，禁用发送并提供移除 |

## 8. 窗口和自适应

- 文档主区最小宽度 520px。
- AI 面板不足空间时优先自动收起。
- 窗口进一步缩小时再收起工作区文件面板。
- 不同时以覆盖层展示文件树和 AI 面板。
- 小窗口中某面板以临时抽屉打开时，另一个抽屉必须关闭。
- 面板宽度记录在本地，重启后按当前窗口尺寸夹取恢复。

## 9. 平台一致性

- 首版使用系统原生标题栏和窗口控制，不模拟 macOS 交通灯或 Windows 窗口按钮。
- 通用布局、功能和颜色保持一致，快捷键使用平台对应修饰键。
- 文件选择、保存、右键菜单、回收站和凭据库使用操作系统原生能力。
- 不在主界面固定展示 Ctrl 或 Cmd 提示；命令显示在系统菜单和对应 tooltip 中。

## 10. 无障碍与输入

- 所有交互元素均可键盘访问，焦点轮廓使用 2px 强调色。
- 文字和背景至少满足 WCAG AA，状态不只通过颜色区分。
- 支持中文 IME 组合输入，组字期间不触发发送、保存或 AI 操作。
- 文本缩放后工具栏、标签和状态栏不重叠。
- 长文件名可省略，但不得挤压图标按钮。
- 鼠标拖动操作必须提供菜单或按钮等价路径。

## 11. 实现顺序

1. 建立深色/浅色设计 token、字体和基础控件。
2. 实现工具轨、文件面板、编辑主区和可收起 AI 面板。
3. 实现文档标签页、CodeMirror、视图切换和状态栏。
4. 实现上下文文件条、消息流和自适应输入区。
5. 实现 AI 修改 diff 审核面板和文档冲突状态。
6. 补齐空态、加载、断线、超时、无权限和上下文超限状态。
7. 在 Windows 和 macOS 上执行键盘、IME、缩放、高对比度和小窗口验收。

## 12. UI 验收标准

- 应用启动后直接进入可操作工作台，不出现营销首页。
- 在 1440 × 900、1280 × 800 和 1024 × 680 三组窗口下无文字、面板和按钮重叠。
- 编辑区始终是最大且最稳定的可见区域。
- 熟悉工具命令使用 Lucide 图标，陌生图标均有 tooltip。
- 文件名、模型名和上下文标签在窄宽度下不会挤出容器。
- AI 发送前可看到全部附加上下文，AI 修改写入前必须经过审核。
- 未保存、已保存、外部冲突和无权限状态可被清楚区分。
- 深色与浅色主题均通过对比度、键盘焦点和中文 IME 测试。
